# Bundled demo model

`nist-test-artifact.stl` is copied from the official NIST download listed on the
[NIST Additive Manufacturing Test Artifact page](https://www.nist.gov/el/intelligent-systems-division-73500/production-systems-group/nist-additive-manufacturing-test).
NIST states that this file was developed by federal employees in their official
duties and is in the public domain under 17 USC section 105. NIST requests
acknowledgement when the file is used.

The source page describes the part as an experimental design that may change;
it is not an ASTM standard, and NIST makes no quality or reliability guarantee.
The demo copies the STL without geometry changes.

## Dashboard demo assumptions

The dashboard pre-fills 120 minutes and 35 g of gray PLA for an FFF printer so
the task can be carried through the application. These are presentation-only
values, not settings or print estimates from NIST, a slicer result, or evidence
that the file has been physically printed. The UI labels them accordingly.
